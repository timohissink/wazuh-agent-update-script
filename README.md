Script controleert automatisch of er een nieuwere versie van de Wazuh agent beschikbaar is. De nieuwste versie wordt opgehaald via de GitHub releases API. Als de agent niet geïnstalleerd is, stopt het script met een foutmelding. Als er een update beschikbaar is, wordt het MSI-pakket gedownload van packages.wazuh.com en stil geïnstalleerd. Alle acties worden gelogd naar `C:\Windows\Temp\wazuh-update.log`.
